# Customer Churn & Retention Analytics with AI

**Author:** Kadeejath Muhsina  
**Dataset:** IBM Telco Customer Churn (7,043 customers · 21 features)  
**Python:** 3.13.7  

An end-to-end machine learning pipeline that predicts customer churn probability, segments customers by AI risk score, explains every prediction with SHAP, generates personalised retention recommendations, and exports a Power BI-ready dashboard workbook.

---

## Dataset

**IBM Telco Customer Churn Dataset**  
- Source: IBM GitHub repository — `telco-customer-churn-on-icp4d`  
- 7,043 customer records · 21 columns  
- Overall churn rate: **26.5%** (1,869 churned / 5,174 retained)  
- Features: Demographics, account info, service subscriptions, monthly/total charges, contract type, payment method

The dataset is downloaded automatically on first run. If internet access is unavailable, a synthetic dataset with identical schema and realistic distributions is generated.

### 1. Install Python dependencies


### 2. Run the full pipeline

```powershell

$env:PYTHONUTF8 = "1"
python run_pipeline.py
```

```bash
# macOS / Linux
PYTHONUTF8=1 python run_pipeline.py
```

**Options:**

```bash
# Fast demo (5 optimisation iterations instead of 40)
python run_pipeline.py --skip-optimize

# Run specific steps only (0 = dataset, 1 = cleaning, … 9 = insights)
python run_pipeline.py --steps 1 2 3

# Re-run only SHAP, recommendations, and Power BI export
python run_pipeline.py --steps 6 7 8
```

```bash
jupyter notebook KadeejathMuhsina_CustomerChurnRetentionAnalytics.ipynb
```

## Engineered Features

| Feature | Formula | Rationale |
|---------|---------|-----------|
| `avg_monthly_spend` | TotalCharges ÷ tenure | Actual average spend rate |
| `charge_per_month_ratio` | MonthlyCharges ÷ (tenure+1) | Spend relative to tenure |
| `num_services` | Count of active add-on subscriptions | Service stickiness |
| `tenure_band` | Ordinal bucket 0–5 (12-month intervals) | Non-linear tenure effect |
| `is_high_value` | 1 if MonthlyCharges ≥ 75th percentile | High-value flag |
| `is_long_term` | 1 if tenure ≥ 24 months | Loyalty signal |

### DAX Measures Used

```dax
-- Total Customers
Total Customers = DISTINCTCOUNT(Customer_Overview[customerID])

-- Churn Rate
Churn Rate = DIVIDE(
    COUNTROWS(FILTER(Customer_Overview, Customer_Overview[actual_churn] = 1)),
    DISTINCTCOUNT(Customer_Overview[customerID])
)

-- High Risk Count
High Risk Count = COUNTROWS(
    FILTER(Customer_Overview, Customer_Overview[risk_segment] = "High Risk")
)

-- Avg Monthly Charges (Churned)
Avg Monthly Churned = CALCULATE(
    AVERAGE(Customer_Overview[MonthlyCharges]),
    Customer_Overview[actual_churn] = 1
)

-- SHAP Feature Importance
SHAP Importance = AVERAGE(Churn_Drivers[mean_abs_shap])
```

## Key Business Insights

1. **Contract type is the #1 retention lever** — two-year contract churn (2.8%) is 15× lower than month-to-month (42.7%)
2. **First 12 months are critical** — 47.4% first-year churn drops to 6.6% after year 5
3. **Fiber optic customers face a value gap** — 41.9% churn rate; need targeted outreach
4. **Electronic check payment signals disengagement** — 45.3% churn vs 15.2% for auto-pay
5. **3,215 high-risk customers** have avg churn probability 88.3% — immediate action needed
